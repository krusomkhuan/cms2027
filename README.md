# CMS วิทยาลัยการอาชีพโพนทอง

ระบบเว็บไซต์ประชาสัมพันธ์ (หน้าบ้าน + หลังบ้าน) — PHP 8 + MySQL/MariaDB + Bootstrap 5
โครงหน้าเว็บอ้างอิงรูปแบบจาก cmtc.ac.th (แถบเมนูสีเลือดหมู, แบนเนอร์ผู้อำนวยการ, แถบดาวน์โหลด, ข่าว/ประกาศ, ตัวเลขผู้เรียน, E-Service)

## ติดตั้ง
1. วางโฟลเดอร์ไว้ที่ `htdocs/cms2027` แล้วเปิด Apache + MySQL ใน XAMPP
2. คัดลอก `config.example.php` เป็น `config.php` แล้วแก้ค่าฐานข้อมูลและ `BASE_URL` (ถ้าจำเป็น)
3. เปิด `http://localhost/cms2027/install.php` → ตั้งชื่อผู้ใช้/รหัสผ่านผู้ดูแลระบบ
4. หลังบ้าน: `http://localhost/cms2027/admin/`

ติดตั้งใหม่: ลบไฟล์ `install.lock` และ drop ฐานข้อมูล `cms2027`

## หน้าบ้าน
| ไฟล์ | เนื้อหา |
|---|---|
| `index.php` | หน้าแรก: สไลด์/แบนเนอร์ผู้อำนวยการ, ดาวน์โหลดเด่น, ข่าวประชาสัมพันธ์, ข่าวประกาศ, สถิติผู้เรียน, E-Service, ผู้บริหาร |
| `news.php`, `news_view.php` | รายการข่าว (กรองหมวด/ค้นหา/แบ่งหน้า), อ่านข่าว + แกลเลอรี + ไฟล์แนบ + แชร์ |
| `personnel.php` | บุคลากร แยกผู้บริหาร/ครู/สนับสนุน และตามฝ่าย/แผนก |
| `students.php` | จำนวนผู้เรียนตามแผนก ระดับ ชั้นปี เพศ เลือกภาคเรียนได้ พร้อมกราฟ |
| `page.php?slug=` | ข้อมูลพื้นฐาน (ประวัติ วิสัยทัศน์ อัตลักษณ์ โครงสร้าง หลักสูตร ติดต่อ) |
| `downloads.php` | เอกสารดาวน์โหลด (นับจำนวนดาวน์โหลด) |

| `events.php` | ปฏิทินกิจกรรมรายเดือน + รายการกิจกรรม |
| `videos.php` | วิดีทัศน์ YouTube (เล่นในหน้าต่างป๊อปอัป) |
| `search.php` | ค้นหาทั้งเว็บ: ข่าว หน้าข้อมูล บุคลากร เอกสาร กิจกรรม |
| `contact.php` | ข้อมูลติดต่อ แผนที่ แบบฟอร์มติดต่อสอบถาม และแจ้งเรื่องร้องเรียนการทุจริต (`?type=complaint`) |

จุดเด่นที่เพิ่มจาก kvc.ac.th: ข้อความวิ่งประกาศ, ปุ่มปรับขนาดตัวอักษร A- A A+, ช่องค้นหา, ไอคอน Facebook/LINE/YouTube,
ปุ่ม LINE ลอย, ปุ่ม “สมัครเรียนออนไลน์”, สารจากผู้อำนวยการ, แท็บข่าวแยกหมวด, ปฏิทินกิจกรรม, วิดีทัศน์, Facebook Page,
สถิติผู้เข้าชม วันนี้/สัปดาห์/เดือน/ทั้งหมด, ฟอร์มติดต่อและร้องเรียน (กันสแปมด้วย honeypot + จำกัดจำนวนครั้ง)

## เว็บ 2 ภาษา (ไทย / English)
- สลับภาษาด้วยปุ่ม TH | EN มุมขวาบน (หรือเติม `?lang=en` ท้าย URL) ระบบจำภาษาไว้ใน session
- ข้อความเมนู/ปุ่มแปลไว้ใน `includes/lang_en.php` (key คือข้อความภาษาไทยที่ใช้ใน `t()`)
- เนื้อหาจากฐานข้อมูลมีช่อง `_en` คู่กัน (ข่าว หน้าข้อมูล หมวด แผนก บุคลากร ลิงก์ กิจกรรม ฯลฯ) — ถ้าเว้นว่างจะแสดงภาษาไทยแทน
- หลังบ้านเป็นภาษาไทย มีแท็บ/ช่อง “English” ในฟอร์ม และหมวด “ภาษาอังกฤษ” ในหน้าตั้งค่า

## ข้อมูลวิทยาลัย
`sql/college_data.sql` เก็บข้อมูลจริง (ที่อยู่ ผู้บริหาร แผนกวิชา วิสัยทัศน์ พันธกิจ ฯลฯ) — `install.php` โหลดให้อัตโนมัติ
สีประจำวิทยาลัย: น้ำเงิน `#1e3a8a` (คุณธรรม) และแดง `#d71920` (ผู้เสียสละและผู้สร้างสรรค์) ปรับได้ที่ “ตั้งค่าเว็บไซต์”

## หลังบ้าน (`admin/`)
ข่าวสาร (ตั้งเวลาเผยแพร่, ฉบับร่าง, ปักหมุด, ภาพปก, ไฟล์แนบ, หลายภาพ) · หมวดหมู่ข่าว · ปฏิทินกิจกรรม · วิดีทัศน์ ·
ข้อความติดต่อ/เรื่องร้องเรียน (เรื่องร้องเรียนเห็นเฉพาะ admin) · บุคลากร · ฝ่าย/แผนกวิชา ·
ข้อมูลผู้เรียน (ตารางกรอกจำนวน ชาย/หญิง) · หน้าข้อมูลสถานศึกษา · สไลด์ · ดาวน์โหลด · ลิงก์/E-Service ·
ตั้งค่าเว็บไซต์ (ชื่อ ที่อยู่ โลโก้ รูปผู้อำนวยการ สีหลัก แผนที่) · ผู้ใช้ (admin / editor) · เปลี่ยนรหัสผ่าน

## ความปลอดภัย
- PDO prepared statements, `password_hash`, CSRF token ทุกฟอร์ม, จำกัดการล็อกอินผิด 5 ครั้ง/5 นาที
- ตรวจนามสกุล + MIME ของไฟล์อัปโหลด, ห้ามรันสคริปต์ใน `uploads/`, ปิดการเข้าถึง `includes/`, `sql/`
- ก่อนขึ้นเซิร์ฟเวอร์จริง: ลบ `DEV_TEST_LOGIN.txt`, ตั้งรหัสผ่าน MySQL และเปิด HTTPS
